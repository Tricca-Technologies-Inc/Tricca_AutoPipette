# Reviewed inventory of every G-code command Klipper registers with this config
# (Klipper 7bc4d09, configs d7c45ce + plan Rev K reference files).
# The offline tests (C-45) fail if Klipper registers a command that is not
# listed here, or if a listed one disappears. Before adding a line, decide how
# the new command can move Z, a plate or the plunger, and add a check + C-test
# if it can (WP2 section 4, umbrella section 6.2).
#
# Classes:
#   CHECKED   can cause motion; goes through the interlock
#   REFUSED   can cause motion; disabled on this machine
#   BYPASS    renamed original, unchecked by design; never send (tapd or by hand)
#   INTERNAL  part of the interlock; harmless to call, but SET_GCODE_VARIABLE on
#             the state/config macros is a bypass (never send)
#   STATE     changes homed/stepper state; conservative (can only unhome)
#   NOMOTION  no motion of its own
#   RESTART   restarts Klipper (everything unhomed)
#   TESTONLY  exists only because the test harness enables [force_move]
#
